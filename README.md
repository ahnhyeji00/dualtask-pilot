# 알림 양식 이중과업 과업 페이지

인간공학실험 6조 주제2 — 시각 작업 중 알림의 제시 양식이 과업 수행과
작업부하에 미치는 영향을 측정하는 실험 과업 페이지.

**실행:** https://ahnhyeji00.github.io/dualtask-pilot/

로그인이나 설치 없이 브라우저에서 바로 돌아간다. 실험이 끝나면 결과가
`.json` 파일 하나로 참가자 컴퓨터에 저장된다. 그 파일을 모아
페이지의 "결과 모아 보기"에서 한꺼번에 불러오면 CSV 하나로 합쳐진다.

## 구성

| 조건 | 내용 |
|---|---|
| A | 대조 검증 단독 |
| B | 시각 알림(아이콘) 단독 |
| C | 청각 알림(알림음) 단독 |
| D | 대조 + 시각 |
| E | 대조 + 청각 |

- 주 과업: 여섯 자리 숫자 열 행의 원본·입력본 대조, 다른 한 행을 클릭
- 보조 과업: 업무 알림 ←, 광고 알림 → (제시 0.5초, 응답 3초)
- 조건 순서: Williams 설계 10개 시퀀스
- 주관적 작업부하: NASA-TLX 비가중 평균(RTLX) 6문항

## 두 가지 실행 범위

- **전체 실험** — 연습, 알림 학습, 다섯 조건 각 2블록, 조건별 RTLX (약 45분)
- **B·C 균형 점검** — 파일럿 3단계만. 두 양식의 식별 난이도가 치우치지
  않는지 확인한다 (약 15분). 끝나면 판정 기준 통과 여부가 표로 나온다

## 결과 수집

기본은 파일 저장이다. 선택적으로 설정 화면에 Google Apps Script 웹앱
주소를 넣으면 구글 시트로도 자동 전송된다.

## 파일

단일 HTML 파일이며 외부 의존은 글꼴뿐이다. 내려받아 더블클릭해도
그대로 동작한다.

### 구글 시트로 자동 수집하기 (선택)

`collector.gs` 의 머리말에 설정 순서가 적혀 있다. 요약하면

1. 구글 스프레드시트를 새로 만든다
2. 확장 프로그램 → Apps Script 에 `collector.gs` 를 붙여넣는다
3. 배포 → 웹 앱, **액세스 권한을 '모든 사용자'** 로 둔다
4. 나온 `.../exec` 주소를 과업 페이지의 "수집 주소" 칸에 붙여넣는다

전송 결과는 브라우저가 읽지 못하므로 시트에 줄이 늘었는지 직접 확인한다.
전송이 실패해도 참가자 컴퓨터의 결과 파일은 그대로 남는다.
